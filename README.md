# Méthode projet

Une façon de travailler avec Claude Code, pareille dans tous les projets de code (jeu, appli mobile, logiciel, site web, outil) : des docs tenues à jour, une mémoire rangée dans le projet, des hooks, et git avec une sauvegarde sur GitHub. Claude lit la méthode complète dans `SKILL.md`.

## Installer sur un PC

1. Installer Claude Code.
2. Récupérer ce dossier, en copie ou avec `gh repo clone <compte>/methode-projet`, et le ranger où tu veux.
3. Faire un clic droit sur `preparer-pc.ps1`, puis choisir « Exécuter avec PowerShell ». Tu peux aussi demander à Claude Code : « lance preparer-pc.ps1 dans le dossier methode-projet ».
4. Faire ce que le script marque « à faire », puis le relancer pour vérifier.

## S'en servir

Dans Claude Code :
- **Nouveau projet :** ouvre un dossier vide et dis « démarre un nouveau projet avec la méthode ».
- **Projet existant, sur un nouveau PC :** ouvre son dossier et dis « reprends ce projet avec la méthode ».
- **Améliorer la méthode :** dis « améliore la méthode : … ». Claude modifie le skill et note le changement dans `CHANGELOG.md`.
